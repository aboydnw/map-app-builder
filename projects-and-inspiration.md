# Projects and Inspiration

This document shows some projects that I would like to use as inspiration, and what specific parts about them we should use. Some projects might be used as guidance for general look & feel, whereas some projects are only used for inspiration of specific components or component design. I will specify for each one.

## List of Necessary Components

First, a list of necessary components that the map-app-builder will need. This will guide which projects I share for inspiration. Some of these we have already built, and some of these still need to be built. Perform comprehensive searches to figure out the best practices for each of these components.

- Map Legend
- Animation player, and video/gif generator based on animation
- Data layer selection
- Additional details panel
- Time series chart, to fit within additional details panel
- Date selector
- AOI selection tool and AOI upload
- LLM chat window - except we don't need to worry about true agent development yet. just the ui component

In your research, if you find other common components, please add them. 


## Projects to inspire look and feel

These projects show a simple, modest look and feel that is modern. It allows the important data and information to be easy to find and is not flashy. Most of the colors are matte or flat and not bright and neon. There are only a few colors in the color palette for each one. This is the look and feel I want on map-app-builder.

- https://explorer.morphocode.com/map
- https://explorer.audubon.org/home?legend=collapse&layersPanel=collapse
- https://www.globalfoodscapes.org/explore-map
- https://climatetrace.org/explore#admin=&gas=co2e&year=2025&timeframe=100&sector=&asset=

## Projects that inspire overall layout

Mapping applications follow a predictable layout. For most of the applications we build, I don't want layout to be a significant question. There should not be any hard rules built into our map-app builder, so if I want to build something different then that should be possible. But, for most apps it should be fairly straightforward.
